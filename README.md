## What It Does

Enter a topic. Topica runs web research and a short survey in parallel, then automatically generates a full learning kit — summary, lecture, flashcards, quiz, and mind map — all as Markdown, stored locally.

A built-in RAG chat lets you ask questions grounded in your own research docs. A knowledge graph tracks prerequisite relationships between topics. Content adapts to your self-reported level (Lv 1–10), calibrated over time by quiz performance.

---

## Philosophy

| Principle | What it means |
|-----------|--------------|
| **Local AI first** | Runs on local models via lm-supply — zero cost, no API key required. Frontier models (OpenAI, Anthropic, etc.) are optional extensions. |
| **Privacy by design** | All data stays on your machine. No telemetry, no cloud dependency, ever. |
| **Generation, not authoring** | You provide the topic; Topica builds the curriculum. It is not a note-taking or document editing tool. |
| **Open source, zero cost** | Quality learning tools should be accessible to everyone. |

## Scope

### In scope

- Topic → auto-generated learning kit (Summary · Lecture · Flashcard · Quiz · Mind map)
- Local AI (lm-supply) with optional frontier API key fallback
- Level-adaptive content (Lv 1–10), adjusted by quiz performance
- Knowledge graph: prerequisite DAG, tag extraction, embedding-based similarity clustering
- RAG-based chat scoped to each topic's research documents
- Windows desktop app (Tauri); macOS/Linux support planned

### Non-goals

Contributions or feature requests in these areas will be declined:

- **Cloud sync / multi-device** — local-only is a core design constraint, not a missing feature
- **Collaboration / content sharing** — this is a single-user learning tool
- **General-purpose AI chat** — chat is topic-scoped Q&A; Topica is not a ChatGPT replacement
- **Manual content editing** — content is generated by AI; manual authoring is out of scope

## Architecture

```
Tauri shell (Rust)
  ├── Frontend  Vite + React + TypeScript
  │               HTTP REST (CRUD) + WebSocket (streaming) — localhost, dynamic port
  └── Backend   C# ASP.NET Core sidecar
                  ├── TopicModule · ContentModule · ChatModule
                  ├── GraphModule · EvaluationModule · AIModule
                  └── SQLite (EF Core) · FluxIndex (vector search)
```

**Stack:** Tauri 2, React 19, TypeScript, C# .NET 8, EF Core 8, SQLite, Zustand,
ironhive-agent, lm-supply, WebLookup, FluxIndex, TokenMeter

## Getting Started

**Prerequisites:** [Tauri v2 prerequisites](https://v2.tauri.app/start/prerequisites/), pnpm, .NET 8 SDK

```sh
git clone https://github.com/iyulab/topica
cd topica
pnpm install
pnpm tauri dev
```

The C# backend starts automatically as a sidecar on a dynamic port. No separate server process needed.
